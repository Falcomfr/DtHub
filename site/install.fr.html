Installer DT Hub, pas à pas

Une seule fois par téléphone, par câble ou sans fil. Ensuite, DT Hub le retrouve tout seul.

1. Télécharger DT Hub

Télécharger DtHub.exe
  • Windows 10 ou 11, 64 bits, rien à installer
  • Au premier lancement, Windows met en garde : voici quoi faire
  • Seuls les appareils Android conviennent. iOS ne permet ni d'ouvrir un écran supplémentaire, ni d'y installer deux fois la même application.

2. Préparer le téléphone

1. Débloquer les options pour les développeurs

Appuyez sept fois de suite sur « Numéro de build ». Un message confirme que vous êtes développeur. Le chemin exact pour votre marque est plus bas.

2. Activer le débogage

Activez « Débogage USB ». Pour jouer sans câble, activez « Débogage sans fil ».

3. Brancher le téléphone

Par câble

Branchez le câble, puis acceptez la demande sur le téléphone en cochant « Toujours autoriser ». Il apparaît alors tout seul dans DT Hub.

Ça ne marche pas ?

  • Déverrouillez le téléphone : la demande ne s'affiche que sur un écran déverrouillé.
  • Essayez un autre câble : beaucoup ne font que charger.
  • Dans la notification USB du téléphone, essayez « Transfert de fichiers ».
  • Options pour les développeurs : « Révoquer les autorisations de débogage USB », puis rebranchez.

Sans fil

Débogage sans fil › Associer l'appareil avec un code d'association. Tapez dans DT Hub le code à six chiffres affiché. Le PC et le téléphone doivent être sur le même Wi-Fi, avec Android 11 au minimum.

Dans DT Hub : « Associer un nouvel appareil », puis suivez la fenêtre.

Ça ne marche pas ?

  • Pour associer, gardez l'écran du code ouvert sur le téléphone : il ne se montre au PC que pendant ce temps.
  • Après un redémarrage, rallumez « Débogage sans fil » : l'association reste acquise.
  • Box à deux réseaux Wi-Fi (2,4 et 5 GHz) : gardez le téléphone sur un seul, le débogage sans fil se coupe quand il change.
  • Le PC et le téléphone sur le même Wi-Fi, pas sur le Wi-Fi invité de la box.
  • Windows : le réseau en « Privé » (Paramètres › Réseau et Internet).
  • Pare-feu Windows : autorisez « Android Debug Bridge » en Privé et en Public.
  • Coupez le VPN du PC, s'il y en a un.
  • En dernier recours : « Saisir l'adresse à la main », dans la fenêtre d'association.

4. Un deuxième compte sur le même téléphone

Chaque compte vit dans son propre profil Android, avec sa copie du jeu. Deux façons d'en ajouter un :

  • Depuis DT Hub : le bouton + sur la ligne du téléphone, puis « Cloner le jeu ». Crée un nouveau profil Android sur le téléphone, avec sa propre copie du jeu, pour un compte de plus. Le jeu y redemandera ses ressources et la connexion.
  • Depuis le téléphone : la fonction de clonage de sa marque, détaillée ci-dessous.

Réglages par marque

Libellés d'un téléphone réglé en français.

Android sans surcouche : Pixel, Motorola, ASUS, TCL, autre

  • Débloquer : Paramètres › À propos du téléphone, ou de la tablette, appuyez sept fois sur « Numéro de build »
  • Options pour les développeurs : Paramètres › Système › Options pour les développeurs
  • Deuxième compte : Utilisateurs multiples, Paramètres › Système › Utilisateurs multiples
  • Batterie, pour que le jeu ne se fige pas : Sans restriction, Paramètres › Applications › DOFUS Touch › Batterie

Xiaomi, Redmi, POCO

  • Débloquer : Paramètres › À propos du téléphone, ou de la tablette, appuyez sept fois sur « Version HyperOS, ou Version MIUI sur les modèles plus anciens »
  • Options pour les développeurs : Paramètres › Paramètres supplémentaires › Options pour les développeurs
  • Deuxième compte : Applications doubles, Paramètres › Applications › Applications doubles
  • Batterie, pour que le jeu ne se fige pas : Aucune restriction, et Démarrage automatique, Paramètres › Applications › Gérer les applications › DOFUS Touch › Économiseur de batterie. Verrouillez aussi le jeu dans les applications récentes, en tirant sa vignette vers le bas : sinon MIUI et HyperOS le ferment au bout de quelques minutes.
  • À savoir : Activez « Débogage USB (réglages de sécurité) », sinon la souris et le clavier ne font rien.
  • À savoir : Android 11 et anciens MIUI : il faut aussi une carte SIM, sinon le réglage saute au redémarrage.
  • À savoir : Clics toujours sans effet (Android 14 et plus) : désactivez « Écriture manuscrite au stylet », en bas des options de développement.

Samsung

  • Débloquer : Paramètres › À propos du téléphone, ou de la tablette › Informations sur le logiciel, appuyez sept fois sur « Numéro de version »
  • Options pour les développeurs : Paramètres › Options de développement
  • Deuxième compte : Profil de travail (Island), l'application Island du Play Store, qui crée un profil de travail où cloner le jeu
  • Batterie, pour que le jeu ne se fige pas : Autoriser l'activité en arrière-plan, Paramètres › Batterie › Limites d'utilisation en arrière-plan › Applications jamais mises en veille. Désactivez aussi « Optimiser les paramètres » dans Paramètres > Maintenance de l'appareil : réactivé, il remet le jeu en veille au bout de quelques jours.
  • À savoir : « Débogage USB » grisé ou téléphone non détecté : désactivez « Bloqueur automatique » (Paramètres › Sécurité et confidentialité), puis « Bloquer les connexions USB ».
  • À savoir : Dossier sécurisé : déverrouillez-le avant de lancer, sinon le jeu n'y est pas trouvé.

OnePlus, OPPO, realme

  • Débloquer : Paramètres › À propos de l'appareil › Version, appuyez sept fois sur « Numéro de build, ou Numéro de version selon la version installée »
  • Options pour les développeurs : Paramètres › Paramètres supplémentaires › Options pour les développeurs
  • Deuxième compte : Clonage d'applications, Paramètres › Applications › Clonage d'applications
  • Batterie, pour que le jeu ne se fige pas : Autoriser l'activité en arrière-plan, réglée sur Sans restriction, Paramètres › Batterie › Utilisation de la batterie › DOFUS Touch. Sur ces surcouches, un « nettoyage automatique » séparé peut fermer les applications à l'extinction de l'écran. Il se désactive dans Paramètres > Batterie > Autres réglages.
  • À savoir : Activez aussi « Débogage USB (paramètres de sécurité) », sinon souris et clavier ne font rien, et « Installer via USB », dans le même menu.

Honor, Huawei

  • Débloquer : Paramètres › À propos du téléphone, ou de la tablette, appuyez sept fois sur « Numéro de build »
  • Options pour les développeurs : Paramètres › Système et mises à jour › Options pour les développeurs
  • Deuxième compte : Double instance d'application, Paramètres › Applications › Double instance d'application
  • Batterie, pour que le jeu ne se fige pas : Lancement d'applications, en mode manuel, Paramètres › Batterie › Lancement d'applications › DOFUS Touch. Passez le jeu en gestion manuelle, puis activez les trois interrupteurs proposés, dont « Exécution en arrière-plan ». La gestion automatique referme le jeu quoi qu'on règle ailleurs.
  • À savoir : Sur les versions sans services Google, le débogage sans fil est parfois absent. Le câble USB reste alors la seule voie.
  • À savoir : Activez aussi « Débogage ADB en mode Charger uniquement » dans les options pour les développeurs, si votre version le propose.

vivo, iQOO

  • Débloquer : Paramètres › À propos du téléphone, ou de la tablette › Infos logiciel, appuyez sept fois sur « Numéro de version, ou Numéro de build selon la version installée »
  • Options pour les développeurs : Paramètres › Autres paramètres › Options pour les développeurs
  • Deuxième compte : Clonage d'applications, Paramètres › Applications › Clonage d'applications
  • Batterie, pour que le jeu ne se fige pas : Consommation en arrière-plan, réglée sur Autoriser, Paramètres › Batterie › Gestion de la consommation en arrière-plan › DOFUS Touch. Activez aussi « Démarrage automatique » pour le jeu. Ces surcouches comptent parmi les plus promptes à fermer une application dès qu'elle quitte le premier plan.
  • À savoir : Activez aussi « Débogage USB (paramètres de sécurité) », sinon souris et clavier ne font rien, et « Installer via USB », dans le même menu.

Amazon Fire

  • Débloquer : Paramètres › Options de l'appareil, appuyez sept fois sur « Numéro de série »
  • Options pour les développeurs : Paramètres › Options de l'appareil › Options pour les développeurs
  • Deuxième compte : Profils, Paramètres › Profils et sécurité familiale
  • Batterie, pour que le jeu ne se fige pas : Optimisation de la batterie, à désactiver, Paramètres › Batterie › Optimisation de la batterie
  • À savoir : Fire OS n'a pas le Play Store : DOFUS Touch n'y est pas distribué, et l'installer demande de passer par un fichier APK. Cette fiche décrit la marche à suivre, elle ne promet pas que le jeu s'y lance.
