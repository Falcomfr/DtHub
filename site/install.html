Install DT Hub, step by step

Once per phone, by cable or wireless. After that, DT Hub finds it on its own.

1. Download DT Hub

Download DtHub.exe
  • Windows 10 or 11, 64 bit, nothing to install
  • Windows warns on first run: here is what to do
  • Only Android devices will do. iOS allows neither opening an extra display nor installing the same application twice.

2. Prepare the phone

1. Unlock the developer options

Tap seven times in a row on “Build number”. A message confirms that you are a developer. The exact path for your brand is further down.

2. Turn on debugging

Turn on “USB debugging”. To play without a cable, turn on “Wireless debugging”.

3. Connect the phone

By cable

Plug in the cable, then accept the request on the phone and tick “Always allow”. It then shows up in DT Hub on its own.

It does not work?

  • Unlock the phone: the request only shows on an unlocked screen.
  • Try another cable: many only charge.
  • In the phone's USB notification, try “File transfer”.
  • Developer options: “Revoke USB debugging authorisations”, then plug it back in.

Wireless

Wireless debugging › Pair device with pairing code. Type the six-digit code it shows into DT Hub. The PC and the phone must be on the same Wi-Fi, with Android 11 at least.

In DT Hub: “Pair a new device”, then follow the window.

It does not work?

  • To pair, keep the code screen open on the phone: it only shows itself to the PC meanwhile.
  • After a restart, turn “Wireless debugging” back on: the pairing is kept.
  • Box with two Wi-Fi networks (2.4 and 5 GHz): keep the phone on one, wireless debugging turns off when it switches.
  • The PC and the phone on the same Wi-Fi, not on the router's guest Wi-Fi.
  • Windows: the network set to “Private” (Settings › Network & internet).
  • Windows firewall: allow “Android Debug Bridge” on Private and Public.
  • Turn off the PC's VPN, if there is one.
  • As a last resort: “Type the address by hand”, in the pairing window.

4. A second account on the same phone

Each account lives in its own Android profile, with its own copy of the game. Two ways to add one:

  • From DT Hub: the + button on the phone's row, then “Clone the game”. Creates a new Android profile on the phone, with its own copy of the game, for one more account. The game will ask again for its resources and the login.
  • From the phone: its brand's cloning feature, detailed below.

Settings by brand

Labels of a phone set to English.

Stock Android: Pixel, Motorola, ASUS, TCL, other

  • Unlock: Settings › About phone, or About tablet, tap “Build number” seven times
  • Developer options: Settings › System › Developer options
  • Second account: Multiple users, Settings › System › Multiple users
  • Battery, so the game does not freeze: Unrestricted, Settings › Apps › DOFUS Touch › Battery

Xiaomi, Redmi, POCO

  • Unlock: Settings › About phone, or About tablet, tap “HyperOS version, or MIUI version on older models” seven times
  • Developer options: Settings › Additional settings › Developer options
  • Second account: Dual apps, Settings › Apps › Dual apps
  • Battery, so the game does not freeze: No restrictions, and Autostart, Settings › Apps › Manage apps › DOFUS Touch › Battery saver. Also lock the game in recent apps, by pulling its card down: otherwise MIUI and HyperOS close it after a few minutes.
  • Good to know: Turn on "USB debugging (Security settings)", or the mouse and keyboard do nothing.
  • Good to know: Android 11 and older MIUI: a SIM card is also needed, or the setting drops at restart.
  • Good to know: Clicks still do nothing (Android 14 and up): turn off "Stylus handwriting", at the bottom of the developer options.

Samsung

  • Unlock: Settings › About phone, or About tablet › Software information, tap “Build number” seven times
  • Developer options: Settings › Developer options
  • Second account: Work profile (Island), the Island app from the Play Store, which makes a work profile to clone the game into
  • Battery, so the game does not freeze: Allow background activity, Settings › Battery › Background usage limits › Never sleeping apps. Turn off Auto optimise daily as well, under Settings > Device care: switched back on, it puts the game back to sleep after a few days.
  • Good to know: "USB debugging" greyed out or phone not detected: turn off "Auto Blocker" (Settings › Security and privacy), then "Block USB connections".
  • Good to know: Secure Folder: unlock it before launching, or the game is not found there.

OnePlus, OPPO, realme

  • Unlock: Settings › About device › Version, tap “Build number, or Version number depending on the release installed” seven times
  • Developer options: Settings › Additional settings › Developer options
  • Second account: App Cloner, Settings › Apps › App Cloner
  • Battery, so the game does not freeze: Allow background activity, set to Unrestricted, Settings › Battery › Battery usage › DOFUS Touch. On these skins, a separate auto-clean can close apps when the screen goes off. It is turned off under Settings > Battery > More settings.
  • Good to know: Also turn on "USB debugging (Security settings)", or mouse and keyboard do nothing, and "Install via USB", in the same menu.

Honor, Huawei

  • Unlock: Settings › About phone, or About tablet, tap “Build number” seven times
  • Developer options: Settings › System & updates › Developer options
  • Second account: App twin, Settings › Apps › App twin
  • Battery, so the game does not freeze: App launch, set to manual, Settings › Battery › App launch › DOFUS Touch. Switch the game to manual management, then turn on the three switches offered, Run in background included. Automatic management closes the game whatever you set elsewhere.
  • Good to know: On builds without Google services, wireless debugging is sometimes missing. The USB cable is then the only way.
  • Good to know: Also turn on “Allow ADB debugging in charge only mode” in the developer options, if your version offers it.

vivo, iQOO

  • Unlock: Settings › About phone, or About tablet › Software version, tap “Version number, or Build number depending on the release installed” seven times
  • Developer options: Settings › More settings › Developer options
  • Second account: App Clone, Settings › Apps › App Clone
  • Battery, so the game does not freeze: Background power consumption, set to Allow, Settings › Battery › Background power consumption management › DOFUS Touch. Turn on Autostart for the game as well. These skins are among the quickest to close an app the moment it leaves the foreground.
  • Good to know: Also turn on "USB debugging (Security settings)", or mouse and keyboard do nothing, and "Install via USB", in the same menu.

Amazon Fire

  • Unlock: Settings › Device Options, tap “Serial Number” seven times
  • Developer options: Settings › Device Options › Developer Options
  • Second account: Profiles, Settings › Profiles & Family Library
  • Battery, so the game does not freeze: Battery optimisation, to be turned off, Settings › Battery › Battery optimisation
  • Good to know: Fire OS has no Play Store: DOFUS Touch is not distributed there, and installing it means going through an APK file. This card describes the steps; it does not promise the game will run.
