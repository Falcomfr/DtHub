Built for DOFUS Touch

  • Windows at the size the game requires
  • Display cut for the game
  • Found on every Android profile, whatever its id
  • Closing a window really disconnects the character

The windows

  • One account per Android profile
  • All at the same size, the same place
  • Or all of them in a tabbed frame
  • Four sizes from the keyboard, and full screen
  • Tiling in one shortcut
  • A window can be locked

The panel

  • Ctrl+P shows or hides it
  • Your phones and their accounts
  • A colour per account, on its row and on its tab
  • What each account is doing, and for how long
  • The Android profile behind each one
  • How each phone is doing, charge and link
  • Open or close an account in one click
  • Battery, heat, slow Wi-Fi: it warns

The guides

  • The guides from papycha.fr, beside the game
  • Ctrl+Q shows or hides them
  • 782 quests, 83 dungeons, 2 raids, 8 lairs
  • Sorted by level, size and area, in aligned columns
  • The steps, and where you were

The Almanax

  • The day's offering and who to bring it to
  • The bonus, written out in full
  • The quest and the meryde
  • The week at a glance

Download

Download DtHub.exe SHA256 checksum · all releases
  • Windows 10 or 11, 64 bit
  • Android 11 or later, with a cloned profile
  • An internet connection on first launch, for 19 MB of tools
  • Code signing: requested from SignPath Foundation, free for open source projects. The certificate will be issued in their name, not mine.

Windows warns on first run

DT Hub is new and not signed yet, so Windows does not know it. Depending on the PC, one of these two windows appears:

  • "Windows protected your PC": More info, then Run anyway
  • "The publisher could not be verified": Run

Neither reports a virus, and no antivirus engine has found anything in this file. A signing certificate has been requested and a Microsoft analysis is under way. In the meantime, check its checksum, and see why, in French.
